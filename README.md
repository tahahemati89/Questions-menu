# Interactive FAQ Accordion

A lightweight, interactive FAQ accordion built with **HTML**, **Tailwind CSS**, and **Vanilla JavaScript**. Click a question to reveal its answer, and open another question to automatically close the previous one.

## ✨ Features

- **Expandable answers** — click a question to show or hide its answer.
- **Single-open behavior** — only one answer stays open at a time.
- **Click-to-close** — click the currently open question again to collapse it.
- **Smooth transitions** — answer panels animate as they open and close.
- **Rotating indicators** — chevron icons reflect each answer's open or closed state.
- **No JavaScript frameworks** — interaction is handled with plain JavaScript.

## 🛠️ Built With

- **HTML5** — page structure
- **Tailwind CSS** — styling and transitions
- **Vanilla JavaScript** — accordion behavior and DOM interaction
- **Font Awesome** — chevron icons

## 🚀 Run Locally

1. Clone this repository:
   ```bash
   git clone <YOUR_REPOSITORY_URL>
   ```
2. Open the project folder in your code editor.
3. If you want to edit the Tailwind classes, start the Tailwind CLI watch command configured for this project so the compiled CSS updates as you work.
4. Open `index.html` in your browser, preferably with **Live Server** in VS Code.

> **Note:** The compiled CSS file needs to be up to date for newly added Tailwind classes to appear.
